# Automatizar-el-dise-o-preliminar-de-componentes-met-licos
La necesidad es obtener en minutos el modelo CAD preliminar de una pieza auxiliar estándar a partir de su descripción, con medidas exactas y con un aviso cuando la pieza no se puede construir. El ahorro de tiempo se apoya en esta evidencia externa; el proyecto comprueba que usuarios reales obtengan sus piezas sin ayuda.
